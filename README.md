# OpenViCloud support

Two ways to reach OpenViCloud:

- **Public issue**, for questions and trial credit: https://github.com/OpenViCloud/titan-support/issues/new/choose
  Write the Tenant ID from the Profile page of the portal. Never put personal data in the issue: everyone can read it.
- **Private report**, for anything that must not be public: read [SECURITY.md](SECURITY.md).

---

# Hỗ trợ của OpenViCloud

Hai cách liên hệ OpenViCloud:

- **Issue công khai**, cho câu hỏi và xin credit dùng thử: https://github.com/OpenViCloud/titan-support/issues/new/choose
  Ghi Mã tenant ở trang Hồ sơ của portal. Đừng đưa dữ liệu cá nhân vào issue: ai cũng đọc được.
- **Báo cáo riêng**, cho điều không được công khai: đọc [SECURITY.md](SECURITY.md).
